# ReUp Market

The ReUp Market marketplace website. It is a lightweight static site, so it can be previewed without a build step.

## Run locally

```bash
npx serve .
```

Then open the local URL shown in the terminal. Replace the placeholder marketplace links and listing data in `index.html` when connecting production services.
