# Delmar RP

The Delmar RP community website. This is a lightweight static site, so it can be previewed without a build step.

## Run locally

```bash
npx serve .
```

Then open the local URL shown in the terminal. Replace the placeholder Discord links and server address in `index.html` when the production community
